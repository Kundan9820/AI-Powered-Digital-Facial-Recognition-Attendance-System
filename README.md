## 📖 Description

The **AI-Powered Digital Facial Recognition Attendance System** is a smart web-based application that automates attendance management using artificial intelligence and computer vision. The system captures student faces through a webcam, detects and recognizes them in real time, and automatically records attendance in a secure SQLite database.

Built with **Flask**, **OpenCV**, **MediaPipe**, and **Scikit-learn**, the application provides an intuitive dashboard for managing students, training the face recognition model, viewing attendance records, tracking analytics, and exporting reports as CSV files.

### ✨ Key Features
- 👤 Student registration with face capture
- 📷 Real-time face detection and recognition
- 🤖 AI-powered model training using Machine Learning
- ✅ Automatic attendance marking
- 📊 Attendance dashboard with statistics and charts
- 📁 Attendance history with daily, weekly, and monthly filters
- 📥 Export attendance records to CSV
- 💾 SQLite database for secure data storage
- 🌐 Responsive web interface built with Flask, HTML, CSS, and JavaScript

### 🛠️ Tech Stack
- **Backend:** Python, Flask
- **Machine Learning:** Scikit-learn (Random Forest)
- **Computer Vision:** OpenCV, MediaPipe
- **Database:** SQLite
- **Frontend:** HTML, CSS, JavaScript, Bootstrap
